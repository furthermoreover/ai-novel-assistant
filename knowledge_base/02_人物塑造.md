# 人物塑造



## 一、人设是第一公理

来源：今日头条《小说创作底层圣经》

- 90%小说烂尾、弃读、口碑崩盘，根源不是剧情平淡，而是人设逻辑破碎

- 常见错误：先想剧情、再套人物，强行让角色配合剧情，导致人物言行割裂、性格反复、行为无脑

- 顶级创作铁律：剧情服务人设，人设驱动剧情

- 人物在压力之下做出选择时得到揭示，压力越大揭示越深（源自罗伯特·麦基《故事》）



## 二、主角设定要素

来源：网文俱乐部《从零到签约完全指南》

- 主角设定六要素：姓名、年龄、性格、背景、目标、金手指

- 人物要有反差，尽量表里不一，内心绝不能和外表一模一样

- 让主角不像主角：给反差属性——他外表怎样但内心怎样，有一个普通人会有的缺点，这个缺点在某些场景里反而成为优势

- 主角必须有一个"软肋"：不是技能弱点，而是会让他在关键时刻做出"看似不合算"选择的情感软肋



## 三、人物小传（6大模块）

来源：B站人物小传教学

1. 角色概述（画骨架）：核心标签（年龄、性格、样貌要具体）

2. 人物动机与目标：他为什么行动

3. 背景故事

4. 性格特质与缺陷

5. 人物关系

6. 弧光成长（从角色设定到弧光成长全覆盖）



## 四、人物立体度（真人化升级）

来源：麟狐工作室小说创作助手

- 主要人物必须同时包含5条：表面身份/隐藏身份、关键特点、独特设定、迷人之处、致命缺陷

- 避免"25岁，有系统，很厉害"式的扁平设定

- 立体人物 = 人设外壳 + 灵魂冲突 + 成长变化



## 五、人物弧光

来源：抖音人物弧光教学、番茄作家专区、晋江论坛《故事》理论

- 弧光定义：角色从A状态到B状态的转变，起点是信念或缺陷，终点是改变或毁灭

- 有完整弧光的主角，作品评分平均比没有的高出0.9分

- 弧光本质不是变强，是信念变了：如甄嬛从"相信真心"到"只有权力可靠"

- 正向弧光：持有错误信念，被现实打碎后建立新信念（鸣人从求关注到求认同）

- 负向弧光：持有正确信念，被现实摧毁（如《绝命毒师》老白）

- 人物弧光四步（麦基）：①铺陈人物塑造特征 → ②真实本性在选择中得到揭示 → ③深层本性与外部面貌冲突对照 → ④揭露深层本性

- 经历了一系列事件的人物一定要有变化，无论变好还是变坏，这种变化构成人物弧光



## 六、角色成长逻辑

来源：番茄作家专区《人物立不住？4个技巧》

- 成长核心逻辑：困境/冲突 → 挣扎/反思 → 改变/突破 → 沉淀/蜕变

- 避免"无理由成长""一蹴而就成长"

- 成长类型：主角成长（核心成长线）、配角成长、关系成长

- 在经历事件后，人物产生性格、认知、行为上的合理变化，既符合人物逻辑，又让读者看到蜕变



## 七、群像塑造（反差标签法）

来源：番茄作家专区《群像塑造秘籍》

- 用反差标签法打造鲜活角色团：每个角色有鲜明且互相区隔的标签

- 人物在巨大的外部压力和转折事件中，在矛盾冲突下做出抉择，既彰显本质，也完成蜕变

- 人物弧光是主角团队不可或缺的部分，从始至终毫无变化的角色会淡化故事意义



## 八、反派设计

来源：阅文作家助手高赞技巧

- 三种高级反派：

  - 棋手型：每一步都在算计，双重目的、利用别人动手、留一个没算到的变量

  - 殉道者：目的高尚手段残忍，站得住脚的信念比主角更纯粹，读者停下来想一想，角色就立住了

  - 影子型：藏在主角身边，前期越可靠越好，每件好事背后有伏笔，真相大白时主角人生观被否定

- 永远别为了衬托主角削弱反派，反派越强，胜利越有含金量

- 反派层次（网文俱乐部）：小反派（目光短浅、嫉妒主角、快速解决、用来打脸）；中反派（有智商、实力较强、多次交锋、积累仇恨）；大反派（城府深沉、实力强大、长期对抗、终极对决）

- 反派动机要合理、智商在线（网文俱乐部大纲方法）



## 九、金手指设计

来源：阅文作家助手高赞技巧、番茄爆款创作指南

- 有缺点的金手指比无脑碾压好十倍：功能是什么、副作用是什么、每天只能用几次、限制在关键剧情中放大

- 唯一金手指三原则：唯一核心（避免多金手指设定混乱）、明确限制（冷却时间、能量消耗、场景限制）、场景绑定（与主角身份或剧情目标绑定）

- 金手指要在困境之后立刻出现，但不能立刻解决困境——是"一条能走出去的路"，而不是"已经走出困境"

- 主角看到希望，同时发现这条路布满荆棘，才是欲罢不能的悬念钩子



## 十、人物对话塑造

来源：番茄作家专区《读者为什么划走？网文句式&对白问题全解析》

- 两人关系感自然流出来，不需要额外解释"父亲很关心儿子"

- 年龄越大、身份越稳的人，通常更少说废话，更少把情绪摊开说

- 亲近关系不代表说话一定温柔，很多亲情恰恰通过责备、打断、嘴硬表现

- 对话有来有回：重点不在于说了多少，而在于人物之间真实互动



## 十一、死亡与遗憾写作（情绪向人物塑造）

来源：阅文作家助手高赞技巧

- 死亡三种写法：

  - 差一点就能到达的遗憾：铺垫期待→给希望→在最高点掐灭，细节越小越日常，扎心越狠

  - 带着误解死亡：先让读者恨他，再让读者后悔恨过他（制造误解→带骂名死→逐步揭开→情绪反转）

  - 极致的平淡：不写死亡写空缺（习惯性呼唤、多买了一份、下意识寻找、成功时的缺席）

- 前提：想让读者哭，先让读者爱上这个角色，写日常互动细节
