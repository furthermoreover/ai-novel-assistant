# 平台规则与签约



## 一、各平台签约字数要求

来源：网文俱乐部《新人作者常见问题100问》

| 平台 | 字数要求 | 其他要求 |

|---|---|---|

| 起点/创世 | 3万字+ | 质量合格，有潜力 |

| 纵横 | 3万字+ | 更新稳定 |

| 晋江 | 2万字+ | 质量优先 |

| 番茄 | 5000字+ | 门槛很低 |

| 七猫 | 5000字+ | 易签约 |

- 字数只是基础，质量、数据（收藏）更重要；建议写到5万字再申请，保证前5万字质量，准备好详细大纲



## 二、番茄小说签约流程

来源：番茄小说作家专区《番茄签约最全流程详解》、番茄官方帮助中心

- 完成实名认证后，作品字数达到2万/5万/8万字时各有1次签约申请机会

- 每次签约评估失败后（不含安全审核失败），需修改作品质量并达到下一阶段字数要求后才能再次申请

- 签约评估门槛2万字；作品签约后可获得番茄小说APP及今日头条APP推荐

- 2026年签约卡点技巧：字数区间8.2-9.5万避开整数最稳，首选8.2-8.5万字（新人推荐，门槛低竞争小）；次选9-9.5万字

- 番茄发布限制：首章满1000字才进入待审列表，新书审核通常2个工作日内给结果；单章不得超过20000字，官方建议章节2000-6000字；作品简介需20-500字

- 作品字数发布按作者等级限制：Lv.0/Lv.1每日<1万字、每月<25万字；Lv.2/Lv.3每日<2万字、每月<50万字；Lv.4及以上每日<5万字、每月<100万字



## 三、各平台上架要求

来源：网文俱乐部《新人作者常见问题100问》

| 平台 | 上架字数 | 上架条件 |

|---|---|---|

| 起点/创世 | 20-30万字 | 根据数据决定 |

| 纵横 | 20-30万字 | 编辑安排 |

| 晋江 | 3万字+ | 自主上架或编辑安排 |

| 番茄 | 无需上架 | 直接分成 |

- 影响因素：收藏数、追读率、推荐位效果、编辑评估

- 上架准备：提前准备上架章节、上架当天更新3-5章（10章+更佳）、写好上架感言、优化前文



## 四、每章字数标准

来源：网文俱乐部《新人作者常见问题100问》

| 平台/类型 | 字数 | 说明 |

|---|---|---|

| 起点男频 | 3000-4000字 | 主流标准 |

| 晋江女频 | 3000-5000字 | 略长 |

| 免费平台 | 2000-3000字 | 偏短，节奏快 |

| 高潮章节 | 5000-8000字 | 可以加长 |

- 不要忽长忽短，保持相对稳定；关键处不要断章



## 五、黄金字数（开篇）

来源：什么值得买《开篇定生死》

- 番茄小说：前3000字定生死，首章1500-2000字；前三行留存率决定算法是否推流，80%用户因无强钩子3秒内划走

- 起点中文网：首章2000-3000字最佳；支持稍慢热铺垫，但第一章必须亮金手指+核心冲突



## 六、签约看哪些指标

来源：网文俱乐部《新人作者常见问题100问》

1. 内容质量（最重要）：文笔通顺、逻辑合理、人物生动、情节吸引人

2. 市场潜力：类型是否热门、套路是否成熟、有没有创新点

3. 数据表现：收藏数、推荐票、阅读量、追读比

4. 更新情况：是否稳定更新、更新字数、是否有存稿

5. 大纲规划：是否有完整大纲、预计字数、主线清晰度



## 七、书名技巧

来源：网文俱乐部《从零到签约完全指南》、什么值得买《洋柿子投稿攻略》

- 好书名标准：简短（4-8字）、好记、有特点、体现类型

- 常见模式：《XX系统》《重生之XX》《XX之XX》《我在XX》《从XX开始》

- 示例：✅《斗破苍穹》《完美世界》；❌《一个修仙者的故事》

- 短句式卖点书名比文艺长书名更容易吸引点击；书名20万字前不可修改（番茄）



## 八、简介技巧

来源：网文俱乐部《从零到签约完全指南》

- 200字简介模板：【身份/背景】+【遭遇/转折】+【金手指】+【目标/爽点】

- 示例："少年萧炎，曾是家族天才，却在十四岁时失去斗之力，从天才沦为废物，被退婚羞辱。然而，某天他发现了戒指中的灵魂——药老！三十年河东，三十年河西，莫欺少年穷！"

- 简介要素：主角是谁、有什么特别、遇到什么困境、有什么金手指、要达成什么目标、有什么爽点

- 简介三句话（阅文版）：主角是谁、遇到什么、要干什么



## 九、标签选择

来源：网文俱乐部《从零到签约完全指南》

- 主标签（类型）：玄幻、都市、科幻、历史、游戏

- 副标签（元素）：系统、重生、穿越、逆袭、爽文

- 热度标签：选择当下热门的、不要太冷门、贴合实际内容



## 十、被拒绝签约怎么办

来源：网文俱乐部《新人作者常见问题100问》

- 可能原因：字数太少、质量不够、类型不合适、数据太差、大纲不清晰

- 应对：礼貌询问编辑拒绝原因、自我检查对比同类型作品、写到10万字再申请或尝试其他平台

- 第一本书被拒很正常，不要频繁切书，持续学习提升

- 新人平台选择：快速变现型（番茄流量大、七猫买断模式）；稳定收入型（纵横新人扶持好、17K福利不错）；冲击高收益型（创世比起点竞争小）；不推荐新人一上来就投起点/晋江



## 十一、申请签约方式

来源：网文俱乐部《从零到签约完全指南》

- 最佳时机：字数5-10万字、收藏1000-3000、质量编辑认可、更新稳定持续

- 方式1站内申请：后台提交，等待编辑审核（3-7天）

- 方式2主动联系编辑（内签）：添加编辑联系方式、自我介绍、发作品链接

- 方式3编辑主动联系：数据好被编辑发现，编辑主动站短（最好的情况）

- 申请材料：作品链接、作品数据、详细大纲（30-50万字）、个人联系方式
