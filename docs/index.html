RAG 知识库

内置 12 篇网文写作方法论（黄金三章、爽点节奏、伏笔悬念、玄幻专项…），向量化检索，写作时自动注入相关知识。

🧠

自主剧情 Agent

每分析一章，自动更新人物卡、世界设定、人物关系、伏笔库与剧情时间线，无需手动维护。

🧭

自动规划下一章

基于完整记忆生成下一章大纲与对仗式章节名（如"剑冢将启"），一键按规划新建章节。

✍️

AI 写作

10 个预设写作技能 + 三种记忆注入模式（自动 / 精简状态包 / 完整状态包），省 token 且不丢设定。

💾

长期记忆

所有设定持久化到 PostgreSQL，重启不丢失；单章分析与全量同步带进度条。

🔐

作者账号

注册 / 登录，项目按账号隔离；密码 PBKDF2 加密，登录态 30 天有效。

🧱 技术架构

本地优先 · 数据自有 · 密钥安全。

前端

  • 原生 HTML / CSS / JS
  • 单文件应用，无构建
  • 工作台：人物 · 章节 · AI 写作 · Agent 助手

后端

  • Python 3.10+ / FastAPI
  • psycopg3 / uvicorn
  • PBKDF2 + HMAC Token 认证

数据库

  • PostgreSQL 18 + pgvector
  • 人物卡 / 章节 / 大纲
  • 时间线 / 关系图 / 伏笔库

LLM

  • 智谱 embedding-3（向量化）
  • 千问 / 智谱 写作模型（可切换）
  • API Key 存于本地 .env

🚀 快速开始

本地运行，5 分钟跑起来。

  1. 准备 Python 3.10+、PostgreSQL 18（含 pgvector）、智谱 API Key
  2. 克隆仓库：git clone https://github.com/furthermoreover/ai-novel-assistant.git
  3. 复制 .env.example 为 .env 并填入密钥
  4. Windows 双击 start.bat 一键启动；或 python -m uvicorn backend.main:app --port 8000
  5. 浏览器打开 http://127.0.0.1:8000，注册账号开始创作

详细说明见仓库 README。⚠️ 请勿将 .env 提交到仓库，密钥永不公开。
