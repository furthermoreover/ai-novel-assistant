开卷
快速开始

本地运行，五步开卷。

前置

准备 Python 3.10+、PostgreSQL 18（含 pgvector）、智谱 API Key。克隆仓库后复制 .env.example 为 .env 并填入密钥，双击 start.bat 一键启动。

  1. 克隆仓库
    拉取源码到本地
    git clone https://github.com/furthermoreover/ai-novel-assistant.git
    cd ai-novel-assistant
  2. 创建数据库
    本机 PostgreSQL，默认端口 5432
    psql -U postgres -c "CREATE DATABASE novel_assistant;"
    psql -U postgres -d novel_assistant -c "CREATE EXTENSION IF NOT EXISTS vector;"
  3. 配置密钥
    复制模板并填入你的 API Key 与数据库密码
    cp .env.example .env
  4. 安装依赖
    项目内虚拟环境，自包含可复现
    python -m venv .venv
    .venv\Scripts\pip install -r requirements.txt
  5. 启动
    Windows 双击 start.bat，或手动拉起服务
    .venv\Scripts\python -m uvicorn backend.main:app --port 8000
    # 浏览器打开 http://127.0.0.1:8000

首次启动自动导入 knowledge_base/ 知识库并向量化（需智谱 Key）。详细说明见仓库 README。注意：.env 含密钥，已被 .gitignore 排除，请勿提交。
